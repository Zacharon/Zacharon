Hi, I'm Zach
I build tools that pull public information together and show where every piece came from, mostly civic data and open-source intelligence.

Live Map puts earthquakes, storms, disasters and weather alerts from USGS, NASA, NOAA and GDACS on one live map, each linked to the original report. (code)

OSINT Forge is the Python backend behind it. It scrubs PII, requires human review, and runs in dry-run mode until I approve a live source.

Civic Ledger puts U.S. officeholders in one sortable table: who funds them, how they vote, what they promised. Every number links to its primary source. Early, not deployed yet.

AEOS is how I work with AI coding agents. Project facts live in files, each session gets a bounded handoff, and nothing becomes trusted knowledge until I approve it.

I also send fixes to Open States, which tracks every U.S. state legislature. Right now: Ohio bill actions and West Virginia roll calls.

Much of my code is written with AI agents, and I decide what ships. Mostly TypeScript and Python, plus some C# and Unity for games. Open to freelance work.
