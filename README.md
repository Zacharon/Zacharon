I build tools that pull public information together and show where every piece came from. Much of the code is written with AI agents, and I decide what ships. Mostly TypeScript and Python, plus some C# and Unity for games. Open to freelance work.

## Work you can open

- [Live Map](https://github.com/Zacharon/live-map) puts earthquakes, storms, disasters, and weather alerts from USGS, NASA EONET, NOAA, and GDACS on one map. Each event links to the original report. The site is [liveworldmap.netlify.app](https://liveworldmap.netlify.app/).
- [OSINT Forge](https://github.com/Zacharon/osint-forge) is the Python backend for that map. It scrubs PII, requires human review, and stays in dry-run until a live source is approved.
- [Civic Ledger](https://github.com/Zacharon/civic-ledger) is an early table of U.S. officeholders: campaign money, votes, and promises, with every number meant to link to its primary source. It is not deployed.
- [AEOS](https://github.com/Zacharon/AEOS) is how I work with coding agents. Project facts live in files, each session gets a bounded handoff, and nothing becomes trusted knowledge until I approve it.
- Merged scraper fixes in [Open States](https://github.com/openstates/openstates-scrapers/pulls?q=is%3Amerged+author%3AZacharon): Ohio bill actions, West Virginia Senate roll calls, and Colorado committee votes.

I also run a small home lab: a private network with a written access split, hardened DNS and monitoring, phone alerts, and encrypted backups with a checked restore.
